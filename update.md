# Cross-cutting changes log

- **Offers (INTERVIEW-only):** Backend `OfferServiceImpl.createDraft` message aligned with product wording; `OfferFormPage` lists only INTERVIEW-stage candidates, documents the rule in the UI, disables draft when none qualify, and surfaces API error messages on save.
- **P0 Security - Secrets & Environment:** Removed hardcoded secrets, commented Cloudinary credentials, default JWT secrets, and default database passwords. Configured fail-fast validated `JwtProperties` and created `backend/.env.example`.
- **P0 Security - Database Seeding & Admin Endpoints:** Restricted `DatabaseSeeder` and `DemoDataSeederService` to `@Profile("dev")`. Deleted `SeederController` and revoked unauthenticated seed routes (`/api/v1/seed-admin`, `/api/v1/seed-demo-data`).
- **P0 Security - Interview Scoring IDOR & Data Integrity:** Scored submissions and deletions strictly use the authenticated principal. Blind scoring prevents premature visibility of other interviewers' evaluations. Added validation ensuring criteria belong to the assigned interview template. Enforced that all assigned interviewers must submit before the interview status transitions to `COMPLETED`.
- **P0 Security - Database Dump Endpoint Removed:** Deleted insecure `GET /api/v1/export/database/sql` in-memory dump. Added CSV formula injection sanitization to exports (`=`, `+`, `-`, `@`, tabs).
- **P0 Security - Document Upload Validation:** Implemented `FileValidator` checking extension allowlists, size limits, and magic byte signatures (`%PDF-`, `PK\x03\x04`, JPEG, PNG, WEBP).
- **P1 Foundation - Flyway Migration & Docker:** Added Flyway (`flyway-core`, `flyway-mysql`) with baseline migration `V1__baseline.sql`, root `docker-compose.yml`, `Dockerfile`s for backend and frontend, and comprehensive root `README.md`.
- **P1 Process - Pipeline State Machine & Rejections:** Centralized stage transitions with explicit validation matrix, mandatory rejection reasons, and withdrawal state handling (`WITHDRAWN`). Fixed GET candidate details side-effect. Added multi-application support (`POST /candidates/{id}/applications`) and case-insensitive unique email handling.
- **P1 Process - Offer Lifecycle & Separation of Duties:** Expanded `OfferStatus` (`DRAFT -> PENDING_APPROVAL -> APPROVED -> SENT -> ACCEPTED / DECLINED / EXPIRED`). Enforced separation of duties (creator cannot approve their own offer, HTTP 403). Candidate only transitions to `HIRED` upon offer acceptance. Added optimistic locking (`@Version`).
- **P1 Process - Interview Conflict & Management:** Added past date validation, interviewer schedule conflict detection (409 Conflict), template assignment, cancellation, and rescheduling endpoints.
- **P1 Process - Candidate Notes API:** Implemented full CRUD (`GET`, `POST`, `DELETE`) for candidate notes at `/api/v1/candidates/{candidateId}/notes`.
- **P1 Process - Job Closing & Rejection:** Added `PATCH /jobs/{id}/close`, auto-closing of jobs when headcount is reached, and mandatory job rejection reasons.
- **P1 Security - Session & Refresh Token Revocation:** Implemented token reuse detection: presenting a revoked refresh token revokes all tokens for the user and returns 401. Revoked tokens on password change, reset, role modification, account lock, and deletion. Added `POST /api/v1/users/{id}/resend-invitation`. Fixed frontend storage persistence on token refresh in `lib/api.ts`.
- **P1 Compliance - JPA Auditing & Real Dashboard Metrics:** Added `@EnableJpaAuditing` and `AuditorAware<UUID>` to populate `created_by` and `modified_by` (fixing "System" author). Added `X-Forwarded-For` proxy IP handling and sensitive argument redaction in `AuditAspect`. Replaced fake stats in `AdminDashboardServiceImpl` with live JPA queries and JVM runtime metrics.
- **P1 Process - Interview Email & ICS Calendar:** Added automated email invitations and cancellation notices with generated `.ics` (iCalendar) attachments dispatched upon interview scheduling, rescheduling, and cancellation.
- **P0/P1 Architecture - Removed interviewerId from Feedback DTO:** Eliminated `interviewerId` from `SubmitFeedbackRequest` across backend and frontend, strictly enforcing authenticated principal resolution.
- **P1 Architecture - CurrentUserProvider:** Replaced direct `UserRepository` queries in `JobController`, `JobCommandController`, `JobDetailController`, and `JobPagedController` with a unified `CurrentUserProvider`.
- **P1 Compliance - Expanded @LogAudit Coverage:** Added `@LogAudit` to `createCandidate`, `importCandidates`, `createJob`, `USER_LOGIN`, and `USER_LOGOUT`. Standardized `logout` response to JSON (`{"message": "Logged out successfully"}`).
- **P2 Documentation & Observability:** Integrated `springdoc-openapi` (Swagger UI at `/swagger-ui.html`) and `spring-boot-starter-actuator` (`/actuator/health`). Updated `.cursorrules` and `project-description.txt` to reflect the active 4-role matrix and live backend authentication.
